# Who is using pyiron?
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/pyiron/who-is-using-pyiron/HEAD)

As part of the pyiron website we already collect the publications which not only cite pyiron but actually use it:
https://pyiron.org/publications/

In this repository we analyse those publications to get an overview of the users of the pyiron workflow framework.
